# Audio Samples

This directory contains royalty-free voice samples used by the project for:

- **`sample_audio_1.wav`** — Generic test input for the STT and end-to-end pipeline tests.
- **`sample_audio_2.wav`** — Reference voice clip used by the offline XTTS voice-cloning fallback (`tts/synthesizer.py`) and by several pipeline tests.
